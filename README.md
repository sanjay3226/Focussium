## 💎 The Focussium Manifesto

Modern productivity suites are bloated, distracted, and addicted to tracking you. They take 5 seconds to load, demand monthly subscriptions, and scatter your attention with notifications.

**Focussium is the antidote.**
- **Zero Framework Bloat**: No React, no bundle overhead, no npm runtime dependencies. Pure, razor-sharp modern Vanilla JavaScript, CSS variables, and HTML5.
- **Instant Paint**: Loads in under **60ms** from browser cache with full offline PWA execution.
- **Sovereign Privacy**: Your tasks, thoughts, habits, and focus logs live on **your machine**. Cloud sync is optional, encrypted, and non-blocking.
- **Sensory Excellence**: Glassmorphic dark aesthetics, FM-synthesized tactile audio, ambient soundscapes, and typographic balance.

## ⏱️ Adaptive Pomodoro & Ambient Studio

Focussium re-imagines the Pomodoro technique as a sensory flow state container:

- **Custom Interval Rhythms**: Configure custom Focus (`25m`), Short Break (`5m`), and Long Break (`15m`) durations with session cycle counters.
- **Minimalist Fullscreen Zen View**: Press <kbd>F</kbd> to strip away all UI, leaving only the glowing serif timer digits and subtle ambient glow.
- **Integrated Tactile Synthesis**: Audio feedback isn't sourced from bulky MP3 files. Every button tap and session completion chime is synthesized in real time via the **Web Audio API** using custom oscillator frequencies, feedback delay lines, and gentle exponential gain decays.

### 🎧 Ambient Soundscape Engine

```
[Web Audio Engine]
   ├── FM Synthesizer ────────> Oscillator Node ──> Gain Decay ──> Hardware Audio Output
   └── Multi-Track Ambient ───> Weighted Elements ──> Smooth 400ms Crossfade ──> Audio Destination
```

Choose from five acoustically curated background soundscapes:
1. 🌧️ **Gentle Rain**: Soothing rainfall for mental quietude.
2. 🌲 **Morning Birds**: Forest ambiance with high-frequency natural brightness.
3. 🏛️ **Exam Hall / Library**: Rhythmic mechanical clock ticks paired with ambient room tone.
4. 🧠 **Binaural Theta Waves**: Frequency-shifted tones tuned for deep cognitive flow.
5. 🔥 **Campfire**: Warm crackle for cozy evening execution.

## 🚀 Local Installation & Deployment

Because Focussium is built with pure web technologies and zero compilation pipelines, running it locally is instantaneous:

### Option 1: Python
```bash
git clone https://github.com/sanjay3226/Focussium.git
cd Focussium
python -m http.server 8080
# Open http://localhost:8080 in your browser
```

### Option 2: Node.js
```bash
git clone https://github.com/sanjay3226/Focussium.git
cd Focussium
npx serve .
```

### Option 3: Docker
```bash
docker run --name focussium -d -p 8080:80 -v "$PWD":/usr/share/nginx/html:ro nginx:alpine
# Open http://localhost:8080
```

## 🔒 Privacy & Local-First Sovereignty

- 🛡️ **Zero Tracking, Zero Telemetry**: Focussium does not load Google Analytics, Facebook Pixels, or third-party tracking scripts.
- 💾 **Local-First Architecture**: All your data is stored primarily in your browser's `localStorage`. You can run the app forever without an internet connection.
- ☁️ **Resilient Cloud Sync**: If you choose to sign in with Google Firebase, sync occurs quietly in the background with automatic conflict resolution—ensuring local edits always win.
- 📦 **Data Freedom**: Export your complete database at any time in standard JSON, PDF, or high-DPI image format.
